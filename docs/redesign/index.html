What changed everywhere

  • One tappable colour: deep ink-blue (#1F3BD6, #9DA8FF at night) replaces the pure #0000FF.
  • Depth: page, card, raised and sunken surfaces instead of hairlines alone.
  • Money: Inter Tight with tabular figures; amounts line up in columns and never wrap.
  • Motion: springy sheets, rows that settle in, rolling totals and a row that grows into its detail screen; all off with "Remove animations".
  • Loading: the shape of the page instead of a spinner, so nothing flashes ₹0.
  • Screenshots: allowed in every build (FLAG_SECURE removed on request).
  • Not shown: Split's empty state (the seeded split exists) and the widget's small size.
